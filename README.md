# 江山时序 · 手机适配版

基于 [DeanChensj/jiangshan-map](https://github.com/DeanChensj/jiangshan-map) 的独立手机适配版，非原作者官方发行。

原作者：DeanChensj / Jiangshan Atlas。修改日期：2026-11-19。GPL-3.0，无担保，完整源码在本仓库。

手机底部导航、朝代入口、本机收藏、安装指引和核心离线缓存。精细 CHGIS 郡州府边界及 DataV 现代省界未包含。

发布方式：仓库 Settings → Pages → Source 选择 GitHub Actions，然后 Actions → Deploy mobile atlas → Run workflow。发布地址会在任务摘要显示。

上传本仓库会公开网页、开源代码与随附说明。未包含账号、令牌、电脑路径配置、测试浏览器数据或隧道访问日志。

iPhone：Safari 打开发布地址 → 分享 → 添加到主屏幕。安卓：Chrome/Edge 打开 → 安装应用。

详见 [使用说明](使用说明.md)、[验证结果](验证结果.md) 和 [许可](LICENSE)。
